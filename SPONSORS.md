# Support Personal Learning Agent

Optional contributions can support Windows testing across CPUs and GPUs, accessibility, local-first research tools, documentation, and better privacy controls.

Visit the [10GODS GitHub profile](https://github.com/10GODS) for available ways to contact or support the project. If the account enables [GitHub Sponsors](https://github.com/sponsors/10GODS), any current tiers and eligibility will be shown there. No particular tier or benefit is implied.

Sponsorship is voluntary and does not grant access to a user's computer, personal datasets, screenshots, research documents, or credentials. Do not include sensitive materials in sponsorship messages.
